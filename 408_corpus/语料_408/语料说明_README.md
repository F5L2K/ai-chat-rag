## 三、清洗规则（build_corpus.py）

1. 剔除空占位文件（源仓库大量 md 是"一片荒芜，期待你贡献笔记"的占位）。
2. 剔除 front-matter（`--- title: ... ---`）。
3. 剔除图片行 / 图片标题（`## ![image](url)` 这类）、纯 URL 行、HTML 标签。
4. 剔除清洗后正文 < 100 字符的文件（只有标题没有文字的截图笔记，对文本检索无意义）。
5. 每科按章节目录顺序合并为一个 UTF-8 无 BOM 的 `.md`，保留原有 ATX 标题层级。
